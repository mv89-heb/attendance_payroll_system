# Attendance & Payroll System — Phase 0

בסיס תשתית פרודקשן (Production Foundation) למערכת ניהול שכר נוכחות. המערכת עושה שימוש בקונקשן פול ל-Neon PostgreSQL, מנגנוני אבטחה שלמים, מניעת כפילויות, והגנת נעילת תקופות שכר ישירות ב-Database.

## טכנולוגיות
- **Python 3.12+**
- **Flask Application Factory**
- **psycopg3 with connection pooling**
- **Neon PostgreSQL**
- **pytest**
- **Gunicorn**

## התקנה מקומית ופריסה
לפרטים מלאים על ההרצה והמיגרציות, עיין במדריך ובדוק שהגדרת את משתנה הסביבה `DATABASE_URL` בתוך קובץ ה-`.env`.

הרצת בדיקות מקומית:
```bash
pytest -v
```
## Phase 2A — תשתית ואפיון למנוע נוכחות ושכר
בשלב זה הוקמה תשתית השכר והנוכחות המלאה של המערכת:
- **היסטוריית תנאי העסקה (`employee_employment_terms`)**: תומך בהגדרת שעתי/חודשי, תעריף בסיס ונסיעות על פני טווחי תאריכים מוגדרים.
- **צימוד משמרות מנורמלות (`ShiftService`)**: עיבוד החתמות IN/OUT גולמיות והפיכתן למשמרות מעובדות מבוססות Work Date.
- **אבטחת שינויי שכר היסטוריים**: טריגרים פנימיים ב-PostgreSQL חוסמים כל שינוי, מחיקה או יצירה של תנאי העסקה בטווח החופף לחודשי שכר נעולים (`LOCKED`).
- **קפיאת שכר היסטורית (`Calculations Snapshot`)**: שמירת snapshot פיננסי מלא המבטיח קפיאה של חישובי העבר.
